# 小组补充分析复核记录

本记录用于区分“可直接进入平台的结果”“修正口径后使用的结果”和“暂不采用的结果”。复核对象包括天气与价格代码、预测结果和时段聚类代码。

## 已采用

- 5分钟天气序列：时间范围与官方数据一致，共8,640个时间点。
- 清洗后的充电时长与充电电量：按247个交通分区在每个时间点取平均，整理为紧凑补充表。
- 小时模式、雨天/非雨天描述统计：用于描述数据，不作因果结论。
- K-Means、标准化和轮廓系数：这些工具本身适合探索性分群，但必须明确聚类对象、候选 K 和特征权重。

## 修正后采用

### 天气相关性

原代码把同一时刻的天气复制到247个交通分区后，在2,134,080行长表上直接计算相关性和独立样本 t 检验。这些行并不是独立天气观测，会放大有效样本量并混入分区规模差异。

平台改为：

1. 每个时间点只保留一条全市观测；
2. 占用使用“全市忙碌桩数 ÷ 18,061根桩”的容量加权口径；
3. 对每个变量减去对应小时的30天均值，再计算相关系数；
4. 雨天/非雨天只展示描述统计，不报告会被伪重复影响的普通独立样本 t 检验。

### 聚类数量

原时段聚类图中，K=2 的轮廓系数约为0.58，高于预设 K=4 的约0.55；代码却直接写入 `best_k = 4`。K=4 可以作为更细的业务切分，但不能称为轮廓系数最优方案。

平台的交通分区聚类现公开比较 K=2–6，默认选择轮廓系数更高的 K=2，同时允许为了细分画像切换其他 K 值。

## 暂不采用

### “快充 / 慢充站点类型”结果

天气代码中的247列是交通分区 `grid_id`，而 `stations_clean.csv` 中是具体充电站 `station_id`。直接用数值编号连接不具备实体对应关系，因此站点类型价格柱状图及相关统计暂不采用。只有获得“站点到交通分区”的正式映射表后才能恢复这部分分析。

### 普通独立样本 t 检验的 p 值

同一时间点的247行共享天气，连续5分钟数据也存在明显时间自相关，不满足普通独立样本检验的观测独立性。若后续需要显著性检验，应优先使用按天聚合、区组/混合效应模型或时间序列稳健标准误，并报告效应量和置信区间。

### 原 K=4 时段聚类作为主结论

原分析只有24个小时样本，却使用7个星期占用特征、总体占用、时长、电量、价格和天气等大量高度相关变量；其中 `rain_prob` 使用“该小时30天内是否曾下雨”的最大值，也不能代表稳定的降雨概率。该结果可用于探索，但不作为平台的主聚类结论。

### 跨目标 RMSE 柱状图

占用、时长、电量和价格使用不同单位，RMSE 数值不可直接横向比较。平台只在同一占用目标、同一测试时间段内比较季节性基线、基础随机森林和天气价格增强模型。
